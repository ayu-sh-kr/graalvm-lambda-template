# Service Maintainer Docs

- Trace callers and side effects before writing KDoc.
- Explain non-obvious business constraints, ordering, retries, idempotency, transaction ownership, and external boundaries.
- For native configuration, explain build-time processing and runtime consequences precisely.
- Keep descriptions short; omit obvious method narration and framework tutorials.
- Describe failures and logs supported by source and tests, without exposing secrets.
