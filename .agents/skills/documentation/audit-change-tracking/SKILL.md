# Audit Change Tracking

- Gather commits, changed source, tests, build output, image identifiers, and deployment evidence available for the requested period.
- Separate source changes, built artifacts, and confirmed deployed behavior. A merged commit is not deployment proof.
- Present a concise chronology with explicit evidence, unresolved gaps, and current operational impact.
- Record JVM, native test, container, and AWS verification independently.
- Save reports under docs/ and link relevant source/evidence; omit secrets and private payloads.
